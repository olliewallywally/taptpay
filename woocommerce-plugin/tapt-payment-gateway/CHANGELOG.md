# Changelog

## 1.1.1 — October16,2026

Unsupported integration is contained: checkout unavailable, payment/refund
initiation refused, historical webhook503, no order/stock/cart/settings changes
or outbound API requests. Existing historical data is retained.

## Earlier versions

Earlier implementation/marketing notes claimed NFC, QR payments, live webhooks,
compliance and pricing. Those claims were not supported by end-to-end evidence
and are superseded by the unsupported status in README.md and readme.txt.
