## Found while implementing

1. **A second preflight omission.** Plan §9.4 asks for a unique index on the processor
   X-ID; the preflight's T4 slice listed only the provider transaction ID (the session ID
   index exists from 0022). The retail X-ID is the first 16 hex characters of the
   attempt's UUID (about 60 random bits), so a duplicate is improbable but not refused by
   the database. A new migration (0035, after a duplicate preflight) is the owner's call:
   see the exit record.
2. **The R2-T4 ADR's reconciliation columns were never written** (it said T5 would). Fixed
   here (08b9dfc3) rather than left as an unmet statement.
3. Two stored-card fixtures were not Windcave's documented shapes (an `/hpp/` link; a
   read-back reply naming another session). Corrected; the code they tested accepted both.
